# Eiskalt erfunden

Escape-Spiel zur Lektionsreihe «Wie entsteht eine Nachricht?» (Medien & Informatik, 2. Sek).
Die Gruppen stoppen eine erfundene Falschmeldung, bevor sie gedruckt wird: 6 Rätsel, eines pro Lektion der Reihe.

## Dateien

| Datei | Zweck |
|---|---|
| `index.html` | Die App – ein iPad pro Gruppe (GitHub-Pages-Link) |
| `umschlaege.html` | Material für die 4 Umschläge zum Ausdrucken (ein Set pro Gruppe) |
| `spielleitung.html` | Anleitung mit Lösungen – **nur lokal**, wird bewusst nicht hochgeladen (`.gitignore`) |

Alle Portale, Personen und Texte im Spiel sind erfunden.
